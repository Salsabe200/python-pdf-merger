# 📄 Python PDF Merger Tool

A clean and simple Python script using `PyPDF2` that allows users to easily combine/merge multiple PDF files into one consolidated document.

---

## 🚀 Features
- **Batch Merging:** Combines any number of PDF files in sequence.
- **File Validation:** Checks for file existence before attempting to merge to prevent crashes.
- **Lightweight:** Fast execution with minimal dependencies.

---

## 🛠️ Built With
- **Python 3**
- Library: `PyPDF2`
